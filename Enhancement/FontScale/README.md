# 字体大小可选增强

一个独立安装包内提供125%、150%、200%三档字体；分别表示原有字体的1.25、1.5、2倍。
适用Steam Windows Build 6307888 + 子非鱼汉化v1.0，保持原汉化独立。

## 使用

- ZIP：`Inquisitor_独立增强补丁_字体可选.zip`。
- 双击 `Files/安装或切换字体.cmd` 选择倍率，再次运行可切换；菜单内也可恢复100%。
- `Files/卸载字体增强.cmd` 恢复100%，保留汉化。
- 工程内自动定位Game目录；压缩包解压到游戏根目录后使用同一入口；放在其他目录时可按提示输入游戏根目录。
- 若安装过旧版125%独立包，安装时验证并移除旧版字体DAT，迁移到统一DAT。以后使用本入口切换。
- 命令行：`powershell.exe -NoProfile -ExecutionPolicy Bypass -File Files/manage.ps1 -Action install -Scale 150 -GameRoot "游戏根目录"`，卸载用 `-Action uninstall`。

## 实现与构建

运行 `python build.py`，三档载荷均从哈希固定的汉化v1.0构建，各只修改三套BFI的TextScaleX/TextScaleY，共6处。
复用 `../../Analysis/font125/` 中REA/Ghidra证据：引擎绘制、测量、折行和行距使用相同缩放参数。
三份候选放在 `Files/Payload/*.bin`，安装时只部署所选档到 `Game/04_enhancement_font.dat`，候选文件不会被游戏自动加载。
位图、原始EXE、汉化03_zh.dat、译文、菜单、设置及存档均不修改。
载荷采用同目录临时文件校验后替换，切换失败时保留既有倍率；安装前统一检查新旧增强文件，未知文件不覆盖或删除。

## 校验与限制

三档各3份字体资源均通过项目解包和QuickBMS独立解包逐字节比较，ZIP CRC及全文件SHA-256通过。
已对最终ZIP在隔离副本完成29项检查：三档安装与双向切换、重复安装/卸载、交互选择/取消/恢复、旧包迁移、未知文件保护、损坏载荷及错误游戏/汉化版本拒绝；结果见 `installer_verification.json`。实际游戏文件未改动。

倍率越高固定区域能容纳的字数越少，200%尤其需要留意对话、任务、物品和属性界面的裁切/溢出。
动态字库里的中文、数字、字母及符号统一缩放；菜单图片文字不变；缩放不增加位图源分辨率。
